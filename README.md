<h2>Description</h2>
SOC + SIEM Home lab for monitoring live attacks from across the world. These attacks comes from everywhere from France to American and everything in between. 
We will create a honeypot in Azure is basically a VM running windows 11. This honeypot will be opened to the internet, by misconfigurating the internal and external firewall setting for the purpose of inviting foreign attacks across the globe.

These attacks will be displayed live on the powershell terminal. Yep, they are still attacking my VM as we speak ☺️
I am still working on how to display them visually.
